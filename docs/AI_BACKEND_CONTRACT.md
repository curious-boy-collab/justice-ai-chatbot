## 1. Overview & Architectural Boundary

The **JusticeAI AI / RAG Module** (`ai/`) is designed to run in close coordination with the **Express.js Backend Server** (`backend/`).

### Communication Model Options:
1. **Direct Module Import (Recommended for Day 1–5):**
   The backend directly requires the AI module:
   ```javascript
   const { askJusticeAI } = require('../ai');
   ```
2. **Internal Microservice (Optional for Day 6+):**
   Backend communicates over localhost HTTP (`http://localhost:5001/api/v1/chat`).

## 2. Request Contract (Backend ➔ AI Service)

When a citizen submits a question through Shravani's frontend, Disha's backend forwards the sanitized request to the AI module.

### Function Signature:
```typescript
askJusticeAI(query: string, language: "en" | "hi"): Promise<AIResponsePayload>
```

### Request JSON Payload:
```json
{
  "query": "How do I check my court case status using CNR number?",
  "language": "en",
  "sessionId": "a8f3b4c1-92d5-4e7a-b9c2-123456789abc"
}
```

### Parameter Validation Rules:
| Field | Type | Required | Constraints |
|---|---|---|---|
| `query` | string | **Yes** | Trimmed, 1 to 1000 characters. |
| `language` | string | Optional | `"en"` (default) or `"hi"`. |
| `sessionId` | string | Optional | UUID for multi-turn session tracking (stored in database). |

## 3. Response Contract (AI Service ➔ Backend)

The AI module returns a standardized, source-backed payload:

```json
{
  "answer": "To check your case status using your 16-digit CNR number, visit https://services.ecourts.gov.in or open the eCourts Services mobile app. Tap 'CNR Number Search', enter your 16-character alphanumeric code without hyphens, and enter the captcha. The portal will display complete case details, hearing history, and daily orders.",
  "language": "en",
  "sources": [
    {
      "title": "Citizen Guide: Current Case Status and CNR Number Lookup",
      "url": "https://services.ecourts.gov.in"
    },
    {
      "title": "Department of Justice – Government of India",
      "url": "https://doj.gov.in"
    }
  ],
  "dataStatus": "official_reference",
  "lastChecked": "2026-11-08"
}
```

### Field Definitions:
- `answer` (string): The natural language response generated by Gemini or the grounded context fallback.
- `language` (string): `"en"` or `"hi"`.
- `sources` (Array<{title: string, url: string}>): Verified government portal links supporting the answer. Frontend renders these as clickable citation cards.
- `dataStatus` (string):
  - `"official_reference"`: Standard verified government data.
  - `"live_api_reference"`: Real-time dynamic response (e.g. future live NJDG integration).
  - `"procedural_guidance"`: General procedural explanation.
- `lastChecked` (string): ISO date (`YYYY-MM-DD`) indicating data verification freshness.

## 4. Error Handling & Guardrails

If an error occurs or no relevant information is found, the AI service returns standard error responses rather than crashing:

### A. Missing or Empty Query (400 Bad Request):
```json
{
  "error": {
    "code": "INVALID_QUERY",
    "message": "Query string cannot be empty.",
    "language": "en"
  }
}
```

### B. Gemini API Rate Limit / Quota Exhaustion (503 Service Unavailable / Graceful Degradation):
The AI service automatically falls back to the local verified context records without throwing a breaking 500 error:
```json
{
  "answer": "[Department of Justice Official Record]: High Courts in India have a total sanctioned strength of 1,114 judges. Monthly vacancy updates are notified by the Department of Justice.",
  "language": "en",
  "sources": [
    {
      "title": "Judges Strength, Appointment Process, and Vacancy Data",
      "url": "https://doj.gov.in/list-of-high-court-judges/"
    }
  ],
  "dataStatus": "official_reference",
  "lastChecked": "2026-11-08"
}
```

### C. Guardrail Violations (Prediction of Court Verdicts / Legal Advice):
The model is instructed to refuse predictions and redirect citizens:
```json
{
  "answer": "As an AI assistant for the Department of Justice, I cannot predict judicial outcomes or give personal legal advice. Please consult an advocate or register for legal advice through the official Tele-Law service at https://www.tele-law.in.",
  "language": "en",
  "sources": [
    {
      "title": "Tele-Law Portal",
      "url": "https://www.tele-law.in"
    }
  ],
  "dataStatus": "official_reference",
  "lastChecked": "2026-11-08"
}
```
