## 1. What is a CNR Number?
The **Case Number Record (CNR)** is a unique 16-character alphanumeric code assigned to every single case filed across any District or Subordinate Court in India.

Format: `XXXX01-000123-2024`
- Characters 1-2: State Code (e.g., DL for Delhi, MH for Maharashtra)
- Characters 3-4: District Code
- Characters 5-6: Court Complex Code
- Characters 7-12: Sequential Case Filing Serial Number
- Characters 13-16: Year of Filing

Because the CNR is globally unique, entering the CNR directly retrieves the complete case dossier without needing to choose state, district, or court name.

## 2. Step-by-Step: How to Check Current Case Status

### Method A: By 16-Digit CNR Number (Fastest)
1. Open [https://services.ecourts.gov.in](https://services.ecourts.gov.in) or open the **eCourts Services Mobile App**.
2. Tap or click on **CNR Number Search**.
3. Enter your 16-digit CNR without hyphens or spaces.
4. Complete the security captcha.
5. Click **Search**.
6. The screen presents:
   - Case Details (Filing Date, Registration Number, Case Type)
   - Case Status (First Hearing Date, Next Hearing Date, Stage of Case, Court Number & Presiding Judge)
   - Petitioner and Respondent Names
   - Advocates appearing
   - Complete History of Case Hearings (Daily Business, Orders, and interim Judgments available as downloadable PDF).

### Method B: Case Number Search (When CNR is not known)
1. Select State, District, and Court Complex.
2. Select Case Type from the dropdown list.
3. Enter Case Number and Year of Filing.
4. Click Search.

### Method C: Party Name / FIR Search
- Litigants can search using their own name or respondent's name.
- In criminal cases, search by entering the Police Station name, FIR Number, and Year.
